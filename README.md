# usage-band

Claude Code のプロンプト入力欄の上に、**5時間セッション**と**1週間**の使用量（レート制限）を常に表示する mod です。

```
⏱️ 5時間  🟢 ███░░░░░░░  30%  🔄 18:00（あと2時間15分）
📅 1週間  🟡 ███████░░░  72%  🔄 11/25(火) 09:00（あと3日4時間）
```

- 使用率に応じて色が変わります（🟢 〜69% / 🟡 70〜89% / 🔴 90%〜）
- バーと使用率（%）、リセット時刻、リセットまでの残り時間を表示します
- リセット時刻は **日本時間（JST, UTC+9）** で表示します
- 認証情報や個人情報は扱いません。Claude Code 本体が持つ使用量の値を表示するだけで、外部への通信もしません

## インストール

ターミナルの Claude Code セッションで、次を入力します。

```
/plugin install usage-band --marketplace sky21peanuts/usage-band
```

`y` でマーケットプレイスを追加し、続けてスコープ（ユーザー / プロジェクト）を選びます。

シェルから行う場合:

```
claude plugin install usage-band --marketplace sky21peanuts/usage-band
```

デスクトップアプリでは `/plugin` が使えません。プロンプト欄の **+** → **Plugins** → **Add marketplace** に `sky21peanuts/usage-band` を入れ、**Add plugin** で追加します。

### インストールせずに試す

リポジトリを clone して、フォルダを直接指定します。

```
git clone https://github.com/sky21peanuts/usage-band.git
claude --plugin-dir ./usage-band
```

## 使い方

インストールすると、入力欄の上に自動で表示されます。操作や設定は要りません。

| 表示 | 意味 |
| --- | --- |
| `⏳ 使用量は最初の応答のあとに表示されます` | まだ使用量が取得できていません。最初の応答のあとに表示されます |
| `⏱️ 5時間 …` | 5時間ウィンドウの使用率とリセット時刻 |
| `📅 1週間 …` | 1週間ウィンドウの使用率とリセット時刻 |
| `✨ リセット済み（次の応答で更新）` | リセット時刻を過ぎました。使用率の更新は次の応答で反映されます |

アンケートが表示されているときは、重ならないよう非表示になります。

## 更新のタイミング（リアルタイム性）

| 項目 | 更新されるとき |
| --- | --- |
| 使用率（%）・バー | Claude Code が使用量の変化を検知したとき（主に応答のたび） |
| リセットまでの残り時間 | 1分ごと |
| 起動直後の値 | セッション開始時に1回読み込み |

定期的に使用量を問い合わせる（ポーリング）わけではありません。別のウィンドウやアプリで使った分は、このセッションで次に応答があるまで反映されません。

## カスタマイズ

[hooks/register.tsx](hooks/register.tsx) を編集します。

- **タイムゾーン**: 先頭付近の `JST` 定数（`9 * 3600 * 1000`）を変えると、表示するタイムゾーンを変えられます
- **色のしきい値**: `dot()` 関数（既定は 70% で 🟡、90% で 🔴）
- **バーの幅**: `bar()` 関数の `width`（既定は 10）
- **ラベル・文言**: `line()` と `register` 内の文字列

## ファイル構成

```
.claude-plugin/plugin.json        mod のマニフェスト
.claude-plugin/marketplace.json   マーケットプレイス定義（/plugin install 用）
hooks/hooks.json                  読み込むモジュールの指定
hooks/register.tsx                本体
types/index.d.ts                  mod が保持する状態の型
```

## 開発

```
claude plugin validate .
```

型チェックは、mod を一度読み込ませると `.claude-plugin/types/` が生成されるので、そのあとで `tsc -p .` を実行します。
